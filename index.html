ComfyUI Video SNS Automation

An open-source Windows workflow for generating short videos and publishing selected clips to connected social accounts.

What the project does

The workflow creates videos with a local ComfyUI installation, sends status notifications through Telegram, and can publish approved output to YouTube, Instagram Reels, and TikTok. Each social platform is configured separately. Posting is disabled until the operator sets up credentials and enables it.

The source code and setup instructions are available in the GitHub repository.

TikTok integration

  1. The operator connects a TikTok account through TikTok Login Kit and grants the requested permissions.
  2. The operator prepares a video, caption, and privacy setting in the local workflow.
  3. The app checks the creator's available posting options, uploads the MP4 through the Content Posting API, and checks the publishing status.
  4. The local log and Telegram notification report the result.

Before TikTok approves the app for public posting, API posts may be limited to private visibility. The integration is being prepared for TikTok review; this page does not offer a hosted posting service.

Get started

Install the project on a Windows machine with a working ComfyUI setup. Follow the repository README for configuration, local credential storage, and platform-specific requirements. Use an account you control for authorization and review each platform's posting settings before enabling automation.

Questions and project feedback can be raised through GitHub Issues.
