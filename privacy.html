Privacy Policy

Last updated: September 24, 2026

ComfyUI Video SNS Automation runs on the operator's Windows computer. When the operator connects TikTok, the tool requests access to the account's basic profile and posting permission through TikTok Login Kit. It reads the account's display name and app-specific ID so the operator can identify the connected account. Access and refresh tokens are saved in a local credentials file, excluded from the public source repository.

When posting is enabled, the tool sends the selected MP4, caption, and privacy setting to TikTok through its Content Posting API. It stores local posting status and error logs. If the operator configures Telegram notifications, the posting result is also sent to the operator's configured Telegram chat. TikTok and Telegram handle data under their own policies.

This informational website does not offer user accounts or use analytics cookies. The project does not sell personal information. The operator can delete local credentials and logs, and revoke the app's TikTok authorization from TikTok account settings. Questions can be raised through the project's GitHub Issues; please do not post tokens or private data there.
